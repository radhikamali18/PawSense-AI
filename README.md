# PawSense-AI
📌 Introduction

PawSense AI is an AI-based web application that analyzes commonly observed dog behaviours and provides a concern-level prediction.

The system uses a Decision Tree Machine Learning algorithm to classify the observed behaviour into:

Normal
Mild Concern
Moderate Concern
High Concern

Note: PawSense AI is an educational support system and does not provide medical diagnosis.

🎯 Objectives
To collect and prepare a dog behaviour dataset.
To apply a Machine Learning algorithm.
To train and test a Decision Tree model.
To predict a concern level based on selected behaviours.
To provide simple guidance and awareness to users.

🤖 Machine Learning Algorithm
Decision Tree

A Decision Tree is a supervised Machine Learning algorithm used for classification.

In PawSense AI, the Decision Tree analyzes the selected behaviour features and predicts the corresponding concern category.
